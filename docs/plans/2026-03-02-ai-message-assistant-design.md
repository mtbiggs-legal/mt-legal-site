# AI Message Assistant Design
**Date:** 2026-03-02
**Status:** Approved

## Overview

Add an AI chatbot to the client portal message thread that automatically replies to every client message on behalf of the attorney. Responses are generated by Claude Haiku with full case context, billed at 0.1 hrs per reply, and logged in the client's billing log. A persistent disclaimer informs clients they are chatting with an AI and that messages are reviewed by their attorney.

---

## Data Model

No new fields. AI responses stored in the existing `messages` array with `from: "ai"`:

```json
{
  "from": "ai",
  "date": "2026-03-02 14:35",
  "text": "Thank you for reaching out... — Endo-Legal Assistant"
}
```

Billing log entry per AI response:
```json
{
  "date": "2026-03-02",
  "hours": 0.1,
  "note": "AI assistant response — [first 60 chars of client message]",
  "type": "ai_message"
}
```

---

## Backend Flow

**Modified route:** `POST /portal/client/message`

On each client message:
1. Save client message to `client["messages"]` (existing behavior)
2. Build system prompt with full case context (see below)
3. Call Claude Haiku (`claude-haiku-4-5-20251001`) with last 10 messages as conversation history
4. Append AI reply to `client["messages"]` as `from: "ai"`
5. Append billing log entry: `0.1 hrs`, `type: "ai_message"`
6. Update `client["hours_billed"] += 0.1`
7. Update `client["last_communication"]` to today
8. `save_client(client)`
9. Return `{"success": True, "ai_reply": "<response text>"}`

**Error handling:** If Anthropic API fails for any reason, still return `{"success": True}` (message was saved) but omit `ai_reply` and skip billing. Frontend falls back to: *"Message sent. Your attorney will respond shortly."*

## System Prompt

```
You are the Endo-Legal Assistant, an AI assistant for Endo-Legal Attorneys At Law, PLLC.
You are responding on behalf of {attorney_display_name}.

Client: {client_name}
Case Type: {case_type}
Legal Issue Summary: {legal_issue}

Your role:
- Provide helpful, professional responses to client questions
- Acknowledge their concerns and keep them informed
- Do NOT give specific legal advice or make promises about case outcomes
- Always remind clients that their messages are saved and will be reviewed by their attorney
- Sign every response as: — Endo-Legal Assistant

Keep responses concise (2-4 sentences). Be warm and professional.
```

Context passed: `client_name`, `case_type`, `legal_issue`, `assigned_attorney` → looked up from `ATTORNEYS` dict for `attorney_display_name`. Last 10 messages passed as conversation turns.

## Client Portal UI

**Disclaimer banner** — always visible at top of Messages tab (not dismissible):

> ℹ You are chatting with the Endo-Legal Assistant (AI). All messages are saved and reviewed by your attorney. Responses may be billed at 0.1 hrs per message.

Styled with a light info background (e.g. `var(--gold)` at low opacity or a blue-gray tint).

**Message bubbles** — new `from-ai` CSS class for AI messages, visually distinct from `from-attorney` (muted blue-gray vs navy). Attribution line below each AI bubble: `Endo-Legal Assistant · {date}`.

**Send flow:**
1. Client clicks "Send Message →" → button disabled, text "Sending…"
2. Server returns `{ success: true, ai_reply: "..." }`
3. Client message + AI reply both appended to thread
4. Thread scrolls to bottom
5. On API error: client message appended, status text shown instead of AI reply
